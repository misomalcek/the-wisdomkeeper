# Sample storycards

These are later regions, so a player can look past the opening without finishing it first.

In the game: Esc, then Storycards, then drop one of these files onto the panel. Continue from the title uses the card you loaded.

- `river` — just after the first gate
- `canopy` — the fractal forest
- `veil` — the void stretch
- `return` — the grove at the end, with the echo-trees carried home
